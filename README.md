# AgentStack

> Hand-curated directory of MCP servers, SKILL.md agent skills, and Claude Code / Cursor / Windsurf plugins.

**Live site:** https://agentstack.it.com (when deployed)
**Status:** Phase 2 — initial build, ready to deploy.

---

## What this is

A static-first directory of AI agent components. Every listing is hand-reviewed and scored (security 0–100, quality 0–100). No user accounts, no database, no login wall. Just static HTML + JSON data + GitHub Actions for status checks.

**Why it exists:** every other MCP/skill directory is an auto-aggregator that doesn't verify, score, or test. This one does.

## Stack

- **Astro 5** — static-first, ships 0KB JS by default
- **Tailwind CSS 3** — utility-first styling
- **JSON files in `/data`** — Git is the "database"
- **Cloudflare Pages** — free hosting, edge cache, 0ms cold start
- **Cloudflare Web Analytics** — privacy-first, no cookies
- **Google AdSense** — monetization (apply once you have traffic)
- **PayPal** — manual sponsored listings
- **GitHub Actions** — weekly status checks + broken link scanner

**Total monthly cost:** $0 (just the domain, ~$1–3/yr on Namecheap promo TLDs).

## Deployment

### 1. Buy the domain (Namecheap)

- Recommended: `agentstack.it.com` (~$1–3/yr on promo, same TLD as sitetrace.it.com)
- Alternative: `agentstack.com` (~$9–12/yr first year) or `agentstack.dev` (~$12/yr)

### 2. Push to GitHub

The repo has been created at https://github.com/appenzellerdigitalstore-stack/agentstack (already done). The GitHub Actions workflows are in `_github_disabled/` because the initial push was made with an OAuth token that doesn't have `workflow` scope. To enable Actions:

```bash
# Locally (on your machine, not the agent):
git clone https://github.com/appenzellerdigitalstore-stack/agentstack.git
cd agentstack
mv _github_disabled .github
git add .github
git commit -m "Enable GitHub Actions workflows"
git push
```

Then go to the repo on GitHub → Actions tab → enable workflows. The status check runs every 6 hours, the broken-link check runs weekly.

### 3. Connect Cloudflare Pages

1. Go to https://dash.cloudflare.com → Pages → Create application
2. Connect to Git → select `appenzellerdigitalstore-stack/agentstack`
3. Build settings:
   - Build command: `npm run build`
   - Build output: `dist`
   - Root directory: `/`
4. Add custom domain: `agentstack.it.com` (Cloudflare will auto-configure DNS if domain is on Cloudflare nameservers; otherwise follow the CNAME instructions)

### 4. Set up Namecheap DNS (if not on Cloudflare NS)

In Namecheap → Domain List → Manage → Advanced DNS:
- CNAME `www` → `agentstack.pages.dev` (automatic)
- For apex (`agentstack.it.com`): use a CNAME flattening provider or move nameservers to Cloudflare

### 5. Enable Cloudflare Web Analytics

In Cloudflare Pages → your project → Analytics → enable Web Analytics. Copy the beacon snippet and paste it in `src/layouts/Layout.astro` (where the comment is).

### 6. Apply for AdSense (after ~1 month of traffic)

1. Apply at https://www.google.com/adsense
2. Once approved, edit `public/ads.txt` with your `pub-` ID
3. Edit `src/layouts/Layout.astro` to enable the AdSense script (uncomment + add your `ca-pub-` ID)
4. Enable Auto ads in your AdSense dashboard

### 7. Submit to directories

Once you have 20+ listings and ~50 visits/day:
- There's An AI For That (TAAFT)
- Futurepedia
- Toolify.ai
- Product Hunt (for the launch announcement)
- The 14 directories from the Phase 1 research

## Maintenance

- **Daily:** new listings (JSON file + commit, 10–20 min each)
- **Weekly:** review and re-score existing listings, respond to sponsor emails
- **Automatic:** status checks every 6 hours, broken link scan weekly, sitemap on every deploy, AdSense serving, click analytics
- **Monthly:** AdSense payout review, content audit, add 5–10 new listings
